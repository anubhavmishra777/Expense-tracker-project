# 💰 Expense Tracker System

## 📌 Project Overview

The Expense Tracker System is a full-stack web application designed to help users efficiently manage and analyze their daily expenses. It allows users to record transactions, categorize spending, visualize data through charts, and gain insights such as budget alerts, monthly predictions, and anomaly detection.

This project focuses on providing a user-friendly interface along with powerful backend logic to make financial tracking simple, interactive, and intelligent.

---

## 🎯 Objectives

* To track daily expenses easily
* To categorize spending automatically
* To visualize data using charts
* To provide smart insights like budget alerts and predictions
* To build a complete full-stack application using modern technologies

---

## 🛠️ Technologies Used

### 🔹 Frontend

* React.js
* Axios (for API calls)
* Recharts (for data visualization)
* CSS (for styling and UI design)

### 🔹 Backend

* FastAPI (Python framework)
* REST API architecture

### 🔹 Database

* PostgreSQL
* Psycopg2 (for database connectivity)

---

## 🔐 Features Implemented

### ✅ Authentication System

* User Signup
* User Login
* Logout with confirmation
* Session management using localStorage

---

### 💸 Expense Management

* Add new expense
* Update expense
* Delete expense
* View all expenses
* Automatic category detection (Food, Travel, Shopping, Others)

---

### 📊 Data Visualization

* Pie chart for category-wise expense distribution
* Color-based segmentation for better understanding
* Tooltip and legend for interactivity

---

### 🚨 Smart Features

* Budget Alert System

  * Safe
  * Warning
  * Overspending

* 📈 Monthly Expense Prediction

  * Based on average spending

* ⚠️ Anomaly Detection

  * Detects unusual high spending

---

## ⚙️ System Architecture

### 🔹 Frontend (React)

* Handles UI and user interaction
* Sends API requests using Axios

### 🔹 Backend (FastAPI)

* Handles business logic
* Processes requests and responses

### 🔹 Database (PostgreSQL)

* Stores user data and expenses securely

---

## 🔄 Workflow

1. User opens the application
2. Login/Signup screen appears
3. After login → Dashboard loads
4. User can:

   * Add expenses
   * View list
   * See charts
   * Get alerts and predictions
